# Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

This is a VS Code runnable front-end demonstration of the project idea.

## Run

1. Open this folder in VS Code.
2. Open `index.html`.
3. Use the VS Code Live Server extension, or simply open `index.html` in a browser.
4. Fill the laptop request form.
5. Click **Submit Request & Run Flow**.

## Project flow

Request Submitted
→ Validate Request
→ Manager Approval
→ Check Inventory
→ Create Procurement Order
→ Notify Employee

## Important

This project is a browser-based simulation of the ServiceNow Flow Designer concept. It does not connect to a real ServiceNow instance or create real procurement orders.

For a real ServiceNow implementation, the same workflow would be created in ServiceNow Flow Designer using triggers, actions, approvals, records, notifications and integrations.
